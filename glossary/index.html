    Connection — 2 meanings

    • Connection (system_Connection) — system. A connection line in an ESD document representing an interconnection between functional blocks (e.g. signals passed between the interfaces of two devices), drawn directly between blocks or between their ports.
    • Connection (system_SdmConnection) — system-sdm. Represents a connection between functional blocks.

    Endpoint — 2 meanings

    • Endpoint (system_Endpoint) — system. One end of a connection in an ESD document, identified by the functional block and the port where the connection line starts or ends.
    • Endpoint (system_SdmEndpoint) — system-sdm. Represents an endpoint of a connection.

    Functional Block — 2 meanings

    • Functional Block (system_FunctionalBlock) — system. Represents a logical block within an ESD document (e.g., MCU subsystem, LED driver block) that stands for a function, operation or device of the system, including parameters, key components, software components, ports, and associations.
    • Functional Block (system_SdmFunctionalBlock) — system-sdm. Represents a logical block within a system functional model.

    Hardware Component — 2 meanings

    • Key Component (system_KeyComponent) — system. A key component of a functional block in an ESD document, shown in the editor as a hardware component (e.g. a Renesas RA MCU chosen with the RA Explorer).
    • Hardware Component (system_SdmHardwareComponent) — system-sdm. Represents a hardware component / part.

    Hardware Project — 2 meanings

    • Hardware Project (des_Project) — design. A design project stored in a Workspace, normally under its built-in version control, such as a PCB project.
    • Hardware Project (system_HardwareProject) — system. An entry of an ESD document for a PCB design project (des_Project) that implements part of the system, listing the functional blocks that project covers.

    Part — 2 meanings

    • Part (lib_Part) — library. A manufacturer part, identified by manufacturer and part number, as held in the Workspace's Part Catalog together with the supplier parts through which it is sold.
    • Part (sup_Part) — supply. Supply Part represents a market-available instance of a manufactured Part, providing aggregated sourcing data such as pricing, stock levels, and supplier offers.

    Port — 3 meanings

    • Port (dm_Port) — deviceModel. A physical port on the device, with its functions, configurations, and connections.
    • Port (system_Port) — system. An interface of a functional block in an ESD document (e.g. the I2C interface of an MPU), placed inside the block's boundaries; connection lines between blocks can start and end at ports.
    • Port (system_SdmPort) — system-sdm. Represents a port within a system design.

    Software Component — 2 meanings

    • Software Component (system_SdmSoftwareComponent) — system-sdm. Represents a software component instance and its dependencies.
    • Software Component (system_SoftwareComponent) — system. Functional in nature, abstracted from but connected to logical implementation.

    Software Project — 3 meanings

    • Software Project (sft_SoftwareProject) — software. The software part of a Renesas 365 solution, developed in the built-in Web IDE (based on the Theia framework) or in e² studio; it can also be created with an external repository type.
    • Software Project (sup_SoftwareProject) — supply. A software project published in the supply catalog, together with the evaluation kits it is compatible with.
    • Software Project (system_SoftwareProject) — system. An entry of an ESD document for a software project (sft_SoftwareProject) that implements part of the system, listing the software components that project covers.
