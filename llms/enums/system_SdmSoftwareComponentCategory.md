| Value | Description |
| --- | --- |

| `MIDDLEWARE` | Functional stacks (e.g., Motor Control, USB, TCP/IP). |
| `OPERATING_SYSTEM` | Kernel or RTOS components. |

| `LIBRARY` | Static utility code or mathematical libraries. |
