# dm_AddressBlockType

- Name: `dm_AddressBlockType`
- IRI: `dm:AddressBlockType` (https://w3id.org/altium/cdm/deviceModel/AddressBlockType)
- Kind: enumeration
- HTML page: [enums/dm_AddressBlockType/](../../enums/dm_AddressBlockType/)

Specifies the type of address block within the device's memory map.

## Values

| Value | Description |
| --- | --- |
| `Memory` | Address block represents a memory region (e.g., RAM, Flash). |
| `Peripheral` | Address block represents a peripheral device (e.g., UART, GPIO). |
